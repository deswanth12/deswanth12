## 🎀 Featured Projects

### 🛠️ Developer Tools & Systems
- **[RepoLens](https://github.com/deswanth12/repolens)** `Python` `AST` `Tree-Sitter` `CLI`  
  Local-first static analysis CLI (`pip install repolens-toolkit`) that maps codebase architecture via AST to generate instant contributor onboarding guides.

- **[Sagiro](https://github.com/deswanth12/sagiro)** `Flutter` `Dart` `SQLite` `Privacy`  
  100% on-device personal budget companion with automated bank SMS parsing and smart local categorization rules.

- **[Cyber Security Toolkit](https://github.com/deswanth12/Cyber-Security-Toolkit)** `Python` `SQLite` `Networking`
